# Elden Tracker

Suivi de progression Elden Ring : https://eyji.github.io/elden-tracker/

Ce dépôt ne contient que le site publié (`docs/`). `docs/progress.json` est poussé
automatiquement depuis le PC de jeu ; le reste (`index.html`, `catalog.json`, la carte)
est recopié depuis le dépôt de développement.
